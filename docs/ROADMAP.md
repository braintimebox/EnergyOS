# EnergyOS Roadmap

## Phase 0 — Product discovery
- [x] Create repository and product overview.
- [x] Define minimal inputs and situational product loop.
- [x] Specify a 14-day exploratory pilot.
- [x] Draft transparent decision rules.
- [ ] Review rules and thresholds before implementation.
- [ ] Define a simple pilot log/export format.

## Phase 1 — Functional prototype
- [ ] Create a SwiftUI iOS project.
- [ ] Build Today screen and fast check-in.
- [ ] Implement local persistence.
- [ ] Implement deterministic recommendation engine.
- [ ] Show one mission with a rationale.
- [ ] Add complete / skip / not-feasible feedback.
- [ ] Add XP without streak penalties.
- [ ] Add basic weekly review.
- [ ] Add data reset/export.

## Phase 2 — 14-day pilot
- [ ] Test with real workdays and days off.
- [ ] Measure check-in time and completion.
- [ ] Measure mission feasibility and completion.
- [ ] Review app-caused burden and safety.
- [ ] Adjust one major mechanism at a time.
- [ ] Document results and limitations.

## Phase 3 — Optional integrations
- [ ] Add HealthKit sleep import behind explicit permission.
- [ ] Add local notifications with quiet hours.
- [ ] Validate data provenance and missing-data handling.
- [ ] Consider widgets only after the main loop proves useful.

## Phase 4 — Evidence-driven expansion
- [ ] Decide whether AI interpretation adds measurable value.
- [ ] Decide whether TickTick integration is worth its maintenance cost.
- [ ] Decide whether any financial tracking belongs in the product.
- [ ] Add cloud sync only if a concrete user need justifies the privacy and reliability cost.

## Definition of done for MVP

A user can complete a quick check-in, receive one explainable mission, report feasibility, and review a week of real data without an account or network connection.
